================================================================
ระบบบันทึกและคำนวณเงิน OT (Personal OT Tracker) สำหรับ Windows
================================================================

โปรแกรมนี้ทำงานแบบ Offline 100% บนเครื่อง Windows 10 และ Windows 11
โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต และไม่ต้องติดตั้งโปรแกรมเสริมใดๆ เพิ่มเติม

----------------------------------------------------------------
วิธีเปิดใช้งาน:
----------------------------------------------------------------
วิธีที่ 1 (แนะนำ):
1. ดับเบิลคลิกไฟล์ "ติดตั้งโปรแกรม (Install).bat" เพื่อสร้างไอคอนทางลัด
2. จะมีไอคอน "ระบบบันทึก OT" ปรากฏบนหน้าจอ Desktop และเมนู Start
3. สามารถดับเบิลคลิกไอคอนบนหน้าจอเพื่อเปิดใช้งานได้ทันที

วิธีที่ 2 (เปิดตรงโดยไม่ติดตั้ง):
- ดับเบิลคลิกที่ไฟล์ "OT-Tracker.vbs" (เปิดเงียบๆ ไม่มีหน้าจอดำ)
  หรือ "OT-Tracker.bat"

----------------------------------------------------------------
คุณสมบัติของโปรแกรม:
----------------------------------------------------------------
- รันในหน้าต่างแอปพลิเคชันเดี่ยว (Standalone App Window) ผ่าน Microsoft Edge WebView
- บันทึกการทำงานล่วงเวลารายวัน (Daily Progressive Logging)
- สกัดเวลาจากรายงานการลงเวลา (HR_RP_003_TimeToWork.pdf) อัตโนมัติ
- ตรวจทานและกระทบยอดเวลาเข้า-ออกงานจริงกับที่ลงบันทึกไว้
- ส่งออกไฟล์ Excel (หลักฐานการเบิกจ่ายฯ.xlsx) ตาราง 31 วัน ตรงตามแบบฟอร์มราชการ
- ส่งออกไฟล์ Word (รายงานผลการปฏิบัติงานฯ.docx) ตรงตามแบบฟอร์มราชการ
- ปลอดภัยด้วยรหัสผ่าน PIN ส่วนตัว (รหัสเริ่มต้น: 1234)

----------------------------------------------------------------
การถอนการติดตั้ง:
----------------------------------------------------------------
- ดับเบิลคลิกที่ไฟล์ "ถอนการติดตั้ง (Uninstall).bat" เพื่อลบไอคอนทางลัด
- สามารถลบโฟลเดอร์นี้ทิ้งได้ทันทีเมื่อไม่ต้องการใช้งาน
