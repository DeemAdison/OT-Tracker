======================================================================
 คู่มือการใช้งานและติดตั้ง "ระบบบันทึก OT" บนมือถือ Android
======================================================================

ระบบบันทึก OT ได้รับการออกแบบให้รองรับการใช้งานบนมือถือ Android ครบวงจร 
โดยมี 2 วิธีหลักในการติดตั้งและใช้งาน:

----------------------------------------------------------------------
 วิธีที่ 1: ติดตั้งผ่านเบราว์เซอร์ Chrome / Samsung Internet (แนะนำที่สุด ⭐)
 (สะดวก รวดเร็ว ไม่ต้องลงแอป ไม่ต้องเปิด Allow Unknown Sources)
----------------------------------------------------------------------
1. เปิดเบราว์เซอร์ Google Chrome หรือ Samsung Internet บนโทรศัพท์ Android
2. เข้าสู่ URL ของระบบบันทึก OT (หรือเปิดผ่าน Local Network ในวง Wi-Fi เดียวกัน)
3. สังเกตที่แถบด้านล่าง หรือกดที่ปุ่มเมนู 3 จุด (⋮) มุมขวาบนของหน้าจอ
4. เลือกเมนู "ติดตั้งแอป" (Install app) หรือ "เพิ่มลงในหน้าจอหลัก" (Add to Home screen)
5. กดยืนยัน "ติดตั้ง" (Install)
6. ระบบปฏิบัติการ Android ร่วมกับ Google Play Services จะทำการคอมไพล์เป็น 
   "Native WebAPK" ให้ทันทีอัตโนมัติ!
7. ไอคอนแอป "OT Tracker" จะไปปรากฏบนหน้าจอหลักและหน้ารวมแอป (App Drawer)
   - เปิดขึ้นมาเป็นแบบเต็มหน้าจอ (Full Screen) ไม่มีแถบ URL เหมือนแอปแท้
   - ใช้งานได้แบบออฟไลน์ 100% แม้ไม่มีอินเทอร์เน็ต
   - ดาวน์โหลดเอกสาร Excel (.xlsx) และ Word (.docx) ลงเครื่องได้ทันที

----------------------------------------------------------------------
 วิธีที่ 2: บิลด์และติดตั้งไฟล์ .apk โดยตรง (Native Android App)
----------------------------------------------------------------------
ในโฟลเดอร์โปรเจกต์ มีโฟลเดอร์ `android-app` ซึ่งเป็นโปรเจกต์ Android เต็มรูปแบบ 
(รองรับ Java 17, Android SDK 24-34, และ Native File Bridge)

ท่านสามารถบิลด์เป็นไฟล์ .apk ได้ 2 ทาง:

ก) บิลด์ผ่าน GitHub Actions (อัตโนมัติบน Cloud ไม่ต้องลงโปรแกรมในเครื่อง):
   1. อัปโหลด/Push โค้ดโปรเจกต์ขึ้นบน GitHub
   2. ไปที่แท็บ "Actions" บนหน้าเว็บ GitHub
   3. จะมี Workflow ชื่อ "Build Android APK" ทำงานอัตโนมัติ
   4. เมื่อทำงานเสร็จ จะมีไฟล์ `OT_Tracker_Android_APK` ให้ดาวน์โหลดเป็นไฟล์ .apk ได้ทันที

ข) บิลด์ผ่าน Android Studio บนคอมพิวเตอร์:
   1. เปิดโปรแกรม Android Studio
   2. เลือก "Open" แล้วเลือกโฟลเดอร์ `android-app`
   3. รอ Gradle Sync เสร็จสิ้น
   4. ไปที่เมนู "Build" > "Build Bundle(s) / APK(s)" > "Build APK(s)"
   5. ไฟล์ .apk จะถูกสร้างอยู่ที่ `android-app/app/build/outputs/apk/debug/app-debug.apk`
   6. ส่งไฟล์ .apk เข้าเครื่อง Android แล้วกดติดตั้ง (Install) ได้ทันที

----------------------------------------------------------------------
 การจัดเก็บเอกสาร Excel / Word ที่ดาวน์โหลดบน Android
----------------------------------------------------------------------
เมื่อกดดาวน์โหลดเอกสาร "หลักฐานการเบิกจ่ายฯ (Excel)" หรือ "รายงานผลการปฏิบัติงานฯ (Word)"
- ไฟล์จะถูกบันทึกลงในโฟลเดอร์ "ดาวน์โหลด" (Downloads) หรือ `Download/OT_Tracker/` ของมือถือ
- สามารถเปิดดูและตรวจเช็คด้วยแอป Microsoft Excel, Microsoft Word, WPS Office หรือ Google Sheets บนมือถือได้ทันที
