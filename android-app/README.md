# 📱 OT Tracker - Android App

ระบบบันทึกและคำนวณข้อมูลการทำงานล่วงเวลาส่วนบุคคล (Personal OT Tracker) สำหรับโทรศัพท์มือถือ Android

---

## ✨ คุณสมบัติหลัก (Features)
- ⏱️ **บันทึกเวลาทำงานล่วงเวลา (OT):** บันทึกเวลาเข้า-ออกงาน รายละเอียดงานที่ได้รับมอบหมาย
- 💰 **คำนวณเงินตอบแทนอัตโนมัติ:** 
  - วันทำการปกติ: 50 บาท/ชั่วโมง (สูงสุด 4 ชั่วโมง/วัน ไม่เกิน 20:30 น.)
  - วันหยุดราชการ/นักขัตฤกษ์: 60 บาท/ชั่วโมง (สูงสุด 7 ชั่วโมง/วัน หักพักเที่ยง 12:00-13:00 น. อัตโนมัติ)
- 📊 **ส่งออกเอกสารราชการ:**
  - ไฟล์ Excel: ตารางหลักฐานการจ่ายเงินตอบแทนฯ 31 วัน (`.xlsx`)
  - ไฟล์ Word: เอกสารรายงานผลการปฏิบัติงานฯ (`.docx`)
- 🔒 **ปลอดภัย & ออฟไลน์ 100%:** ข้อมูลทั้งหมดถูกจัดเก็บอยู่ในตัวเครื่อง ไม่มีการส่งข้อมูลออกนอกเครื่อง
- 📥 **บันทึกไฟล์ลงมือถือ:** รองรับการบันทึกลงในโฟลเดอร์ `Download/OT_Tracker` ของโทรศัพท์โดยตรง

---

## 🚀 วิธีดาวน์โหลดและติดตั้งไฟล์ APK
1. ไปที่แท็บ **[Releases](https://github.com/DeemAdison/OT-Tracker/releases)** หรือแท็บ **[Actions](https://github.com/DeemAdison/OT-Tracker/actions)**
2. ดาวน์โหลดไฟล์ `app-debug.apk` (หรือ `OT_Tracker_Android_APK`)
3. เปิดไฟล์บนมือถือ Android แล้วกดยืนยันการติดตั้ง (**Install**)

---

## 🛠️ ข้อมูลทางเทคนิค (Technical Specs)
- **Minimum SDK:** Android 7.0 (API 24)
- **Target SDK:** Android 14+ (API 34)
- **Framework:** Android WebView Native Bridge + Vue.js 3 + Tailwind CSS
- **CI/CD:** GitHub Actions Cloud Build
